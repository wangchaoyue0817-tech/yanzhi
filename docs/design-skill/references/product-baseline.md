## 已形成的界面约束

- AI首页为一排五张可见品类卡，缓慢自动轮播，支持拖动；箭头整批切换五项。Hi/WELCOME、探索鉴定技能、全部技能等旧标题已按用户要求删除。
- 问题建议为三行紧凑交错流动内容，带暖金/青蓝小光点。咨询框使用细紫色动态边缘。
- 品类上的“活动 / NEW / 限免”随对应卡片移动，可为空；不能只在中心卡或点击后显示。
- AI与专家Tab使用一致的分段胶囊。
- 专家鉴定保留选择品类 → 品牌 → 款式的既有流程；两个选择弹层同高，品类页两列按用户给定顺序呈现，价格来自既有数据。
- 2026-09-28新增业务层级要求：专家Tab中线上鉴定优先，线下图灵评鉴为次级入口；两个页面改版方案已获确认，六项服务保障必须保持一行，并使用统一线性图标。
