# 图灵鉴X 设计规范

让新页面与现有图灵鉴X属于同一套产品：深靛夜色、蓝紫光谱、克制光感、清晰内容、明确的操作层级。

## 使用方式

1. 开始设计前阅读 [设计规范](references/design-system.md)，按相关组件读取 [现有产品基线](references/product-baseline.md)。规范中的“归一化建议”是新页面默认值，不代表历史页面已全部符合。
2. 先看用户这次的截图与最新要求，再检查目标项目的实际页面及最终生效样式。用户的明确布局、文案、数量、价格和交互要求优先；历史样式不是不可改动的约束。
3. 区分截图角色：认可的风格、需要复刻的布局、仅供提取内容的旧界面、批注标记。黄色框、蓝色批注框、标号不属于产品设计。
4. 复用目标项目的导航、字体、图标、按钮、卡片与弹层。新增样式优先采用 [语义变量](assets/tokens.css)，不要为同一种组件另起一套视觉风格。变量是可移植起点，不是要求全站立即替换。
5. 按用户当前授权推进。用户要求先讨论或确认时，先提供具体方案；已授权开发时完成实现及相应验证，无须因本 Skill 另行申请批准。本 Skill 本身不授权部署、付款、下单或外部发送。

## 品牌约束

- 页面用深靛接近黑的底色，内容层级靠明暗和留白建立。紫色用于品牌强调与选中；蓝色、青蓝用于科技光感；暖金用于价格、少量权益和光点。
- 大面积背景与列表保持安静；光环、渐变文字、较强光线集中在首屏主视觉或主操作。每张卡片都发光、整屏灰紫、满屏金色价格都偏离本产品调性。
- 主按钮用共享蓝紫渐变，次级入口降低面积和光晕；颜色相同不等于优先级相同。专家鉴定内，线上鉴定是主入口，图灵评鉴是次级线下入口。
- 文字以内容层级体现精致感，不用大量英文装饰、小到难读的辅助字或重复标题。用户指定的中文文案保持原义。
- 展示卡片可以有浅透视、轻叠层；表单、选择列表、支付或订单信息采用稳定平面布局。
- 图标使用一致的线性家族与笔画；商品实物图统一比例和留白。避免 emoji、混杂图标、重投影和不清晰素材。

## 交付前核对

- 对照本次参照图核验元素顺序、相对位置、留白与主次；相同组件跨 AI、专家、线下页面保持一致。
- 手机内容基准为 390 CSS px，检查 320、390、430 px；按实际产品需要检查桌面预览。不要直接将截图物理像素用作 CSS 尺寸。
- 检查长品类、金额、两行标题、空结果、禁用和选中状态；不会溢出、遮挡或靠无限缩小文字适配。
- 检查按钮触达、键盘焦点、滚动容器、安全区、减少动态效果设置。动画不阻碍选择与阅读。
- 对比运行页面的实际截图；开发任务同时验证涉及的流程。规范整理任务不需要为了测试而修改页面。
- 给出已完成内容、可查看的产物和必要的待确认事项。不要把静态演示数据描述成已接通的鉴定、支付、寄件或订单能力。

## 规范维护

规范来源和边界见基线文件。只有明确认可的新方向才纳入长期规范；草案留在项目方案文件，不写成既定品牌规则。更新规范时以新用户要求为准，不覆盖用户当前明确选择。
