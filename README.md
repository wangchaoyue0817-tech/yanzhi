# 图灵鉴X 首页 Demo

基于用户提供的首页 HTML 改版。AI 首页为单排五张卡片的弧形轮播，覆盖全部 20 个技能；原专家页 HTML 与原始样式保留。

## 使用

静态网站入口：`public/index.html`。使用任意静态 HTTP 服务运行 `public` 目录。无构建依赖、无外部字体或运行时 CDN。

## 已实现

- 每屏五个品类；自动播放、左右滑动、键盘方向键、暂停/继续。
- 选择技能同步到底部输入栏；完整技能列表保留在“开启技能”内。
- 三张推荐 banner 自动轮播、手动分页、点击进入相应技能或专家页面。
- 三行反向缓慢流动的咨询问题，点击填入输入栏。
- 黄紫动态渐变欢迎语、咨询框流光边缘、减少动态效果偏好支持。
- 最多三张本地图片预览和移除；文本咨询演示；图片不上传服务器。
- 原专家页切换和协议展示，按钮明确提示未接入真实下单。

## 范围

本版本是前端交互演示，不调用真实 AI，不给出鉴定结论，不创建订单、不收费。移动网页并非已发布的微信小程序。原专家页内服务说明为用户原始素材，本次未新增服务承诺。

## 维护

`public/original.css` 为原始样式；`public/data.js` 为原技能列表和 SVG 图标。
`public/app.css` 为基础布局，`public/spectral.css` 为与专家页统一的蓝紫、青蓝、暖金视觉，`public/app.js` 为交互。三张 Banner 与欢迎区光轨位于 `public/assets/*.webp`。

`public/assets/icon-map.js` 映射全部 20 项技能。图标采用 Phosphor 与 Tabler 官方 SVG，来源和 MIT 许可位于 `public/assets/icons/`。
