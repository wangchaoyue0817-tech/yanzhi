# AI 对话过程 Demo

本版只用于查看交互效果。首页上传任意照片并发送后，直接运行本地流程，不读取或检查任何鉴定服务，不发起网络鉴定，不需要 URL 参数或 sample 标记。

## 本地流程

- 本地运行器逐步发送7个环节，40秒后发送完成事件与参考结论。
- 展示当前环节与最近两条，前面记录自动折叠；用户展开历史后保持展开。
- 同ID事件合并，任意数量的环节均由事件列表驱动，界面不写死四步。
- 每条记录可以独立展开详情；全部代码和技术记录默认收起。
- 完成后自动收起过程并展示结论；退出或新建对话取消本轮，迟到回调不再显示。
- 动态光点、活动光带与耗时保留，不显示虚构的百分比。

## 数据边界

本地文案、点位和结论沿用已确认的截图参考案例，与用户所上传的具体内容无关，不代表真实鉴定。图片仅在浏览器本机预览。`?appraisal=demo` 只用于预填已有参考照片，普通上传同样可完整运行。

## 内部事件

`step` 更新环节（id、title、detail、active/done、technical）；`complete` 输出参考结果（title、paragraphs、rows）；`stop` 取消。渲染层保留原有事件去重、历史收纳、文本转义与终态隔离能力。
