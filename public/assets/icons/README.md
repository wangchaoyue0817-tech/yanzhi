# Category icons

The default mapping uses 20 untouched official Phosphor regular SVGs from https://github.com/phosphor-icons/core. MIT license in LICENSE. All use fill=currentColor, viewBox 0 0 256 256. Their regular stroke silhouette corresponds to approximately 1.5 px on a 24 px display grid. Scale via width/height or CSS mask.

Three optional, more literal category alternatives are supplied from the official Tabler repository, https://github.com/tabler/tabler-icons (MIT license in LICENSE-tabler):

- 鉴美妆: tabler-perfume.svg — https://raw.githubusercontent.com/tabler/tabler-icons/main/icons/outline/perfume.svg
- 鉴邮票: tabler-email-stamp.svg — https://raw.githubusercontent.com/tabler/tabler-icons/main/icons/outline/email-stamp.svg
- 鉴瓷器: tabler-teapot.svg — https://raw.githubusercontent.com/tabler/tabler-icons/main/icons/outline/teapot.svg

Tabler SVGs have a 24 px grid and original stroke-width=2; setting stroke-width=1.5 gives the same effective weight as Phosphor regular. Geometry is unmodified. Use the default mapping for the purest single-library consistency, or substitute these three for more literal recognition.

No project files were edited. Preserve the relevant MIT license text when shipping the chosen assets.
