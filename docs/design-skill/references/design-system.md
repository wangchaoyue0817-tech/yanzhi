# 图灵鉴X 设计规范 v1

整理日期：2026-09-28。适用：图灵鉴X、AI鉴定、专家鉴定、图灵评鉴。

基于当前 jianx-home 页面与实际样式归纳；色值与渐变源自现有产品，字号、间距和组件尺寸做了归一化，作为新页面默认标准。线上与线下鉴定改版方案已获用户确认；线下服务六项保障明确保持一行，使用统一线性图标。

## 1. 风格与视觉层次

**深靛夜色 · 蓝紫光谱 · 暖金点缀 · 克制科技感。**

专业可信是内容气质；高级感来自清晰比例、留白、薄边界和少量有方向的光。大面积深色承载内容，蓝紫建立品牌识别，青蓝与暖金形成冷暖对比。

- 展示层：欢迎/服务主视觉、技能卡片、Banner。可用局部光环、轨道、细光线、渐变关键词、浅透视。
- 操作层：品类、品牌、款式、表单、弹层、订单。用较平静的深色面板，增加文字对比，突出选择和下一步。
- 一个区域只设一个主要视觉焦点。装饰不穿过正文，不盖住按钮，不比商品或价格更醒目。
- 线上专家鉴定与线下图灵评鉴属于同一服务体系；首页优先呈现线上鉴定，线下入口更小、更安静。

## 2. 色彩角色

| 角色 | 默认值 | 用法 |
| --- | --- | --- |
| 页面深底 | `#050810` | 最深背景与层次基底 |
| 品牌靛底 | `#0F0F2C` | 顶部、底部渐变的靛色端点 |
| 展示面板 | `#151627` | 服务卡片、次级入口 |
| 操作面板 | `#232631` | 品牌/款式列表、信息容器 |
| 主文字 | `#F1F0FF` | 页面标题、重要内容 |
| 正文 | `#BEC3D2` | 描述、列表常态 |
| 辅助文字 | `#AAA9C3` | 说明、次要标签；需检查实底对比 |
| 品牌蓝 | `#595FF2` | 蓝紫渐变起点附近、强调 |
| 品牌紫 | `#7B55EA` | 选中、主操作、柔光 |
| 青蓝光点 | `#6DDFFF` | 科技轨道、少量光点；非通用正文色 |
| 暖金光点 | `#FFD16C` | 点状强调、权益、冷暖对比 |
| 价格金 | `#E4CDA2` | 价格数字；克制使用，不放大成整屏焦点 |
| 常态细边框 | `rgba(166,188,227,.13)` | 面板之间的轻边界 |
| 强調边框 | `rgba(184,169,255,.42)` | 主按钮或重要选中态 |

推荐背景由顶部深靛渐变至中部近黑，在底部放低透明度紫色径向光。避免整个页面铺均匀灰紫色。

**品牌主渐变（现有专家页按钮）：**
`linear-gradient(112deg, #5B68ED 0%, #7753DD 58%, #A660D1 100%)`

**关键词渐变（现有专家标题）：**
`linear-gradient(100deg, #A4DBFF, #ADADFF 35%, #DBABEF 67%, #FFE0A2)`

关键词渐变仅用于短标题中的重点词。长段落、整组品类名和所有按钮文字不使用彩色渐变。错误、成功等反馈保留明确语义，不能用紫色混淆。

## 3. 字体与排版

系统中文无衬线：`"PingFang SC", "SF Pro Text", -apple-system, BlinkMacSystemFont, "Helvetica Neue", sans-serif`。沿用现有字体栈，不引入无必要的远程字体。

下表为新页面归一化建议，以 390 CSS px 手机内容宽度为基准：

| 用途 | 字号 / 字重 | 行高 |
| --- | --- | --- |
| 专家页两行主标题 | 26–28 / 500–600 | 1.4–1.5 |
| 子页面标题 | 20–22 / 600 | 1.35 |
| 区域标题 | 16–18 / 600 | 1.4 |
| 卡片名、关键操作 | 14–16 / 500–600 | 1.4 |
| 正文 | 13–14 / 400 | 1.65–1.85 |
| 辅助说明、状态 | 11–12 / 400 | 1.5–1.65 |
| 列表价格 | 16–18 / 600 | 1.2 |
| 数据数字 | 24–28 / 600 | 1.15 |

重要价格、业务条件、按钮名称不低于 12 px。个别非核心小角标可以紧凑，但不得通过缩小正文塞下内容。现有页面部分 8–10 px 历史样式不是未来规范。

中文正文不加夸张字距；少量英文眉题可用 1–2 px 字距，但不得取代必要的中文标题。小数与金额使用等宽数字；金额写法以业务给定值为准。

## 4. 间距、圆角与边框

- 间距序列：4 / 8 / 12 / 16 / 20 / 24 / 32 px。
- 手机页面左右通常 20–22 px；窄屏可降至 16 px。弹层内容左右 12–16 px，因信息密度调整。
- 普通卡片内边距 14–16 px；同组卡片间距 8–12 px；大区块间距 20–28 px。
- 紧密关联的标题与说明间距 6–8 px；分离的服务模块之间至少保持 16 px 呼吸感。
- 常规卡片圆角 14–16 px；输入框 14–16 px；小标签 8 px 或胶囊；弹层顶部约 24 px；主按钮 14–16 px，短次按钮可胶囊。
- 默认只用 1 px 低透明度描边；浅色内高光限于顶部边缘。阴影透明、柔和、范围小。
- 不用双层粗边框，不为每一块加外发光。保留真实安全区，不能用固定大空白伪装留白。

## 5. 组件规范

### 导航与 Tab

AI鉴定、专家鉴定共享同一胶囊组件，字体、宽度、圆角、选中态和位置一致。选中项用明亮蓝紫底和白字，未选中保持半透明深底与柔和浅字。导航不因切换服务而跳位。

子页面采用同风格导航：返回、中文标题、小程序原生胶囊/安全区；不要在真实小程序重复绘制手机状态栏。

### 按钮

- 主按钮：高 52–54 px、圆角 14–16 px、品牌主渐变、白字 14–16 px、轻微顶部高光。宽度随主操作场景变化，专家首页使用通栏。
- 次按钮：高 36–40 px，短胶囊或相同圆角；沿用主色但缩小面积、减弱光晕。用于“去评鉴”等次级动作。
- 弱操作：深底细描边或文字按钮，不与主 CTA 竞争。
- 图标：通常 18–20 px。箭头使用一个清晰的线性箭头；不使用连续多个 `>>>`。
- 同一视区明确主操作。按下可轻微变暗或缩放至 .98；禁用时降低对比并明确不可用，加载时保留按钮宽度。
- 手机触达区域尽量达到 44×44 px；小胶囊、关闭图标可扩大透明热区，视觉尺寸无需同样变大。

### 卡片与列表

- 服务入口：左侧信息，右侧动作；正文层级为轻眉题 → 服务名 → 简短说明。次级服务卡保持暗面板和微弱局部光。
- 品类卡：图标或商品图、品类名、价格分区清晰；同组一致对齐。分类浏览可用两列，含较多说明的服务优先用紧凑单列。
- 不为普通列表添加扇形透视；技能轮播才使用已有的轻叠层和弧线节奏。
- 商品图使用统一容器和 `contain`，不变形、不剪掉主体；同一列表的图像大小与基线一致。
- 品类角标绑定具体品类数据；“NEW”“活动”“限免”可分别使用蓝、紫、金色。角标随卡片移动，支持无角标，不能由点击或居中状态决定是否出现。

### 表单与弹层

- 选择鉴定品类、选择鉴定产品继续使用同高弹层；当前工程顶部位于导航下约 14 px，随实际导航和视口计算。
- 弹层是近黑蓝灰的独立操作面板，薄边界、顶部圆角；遮罩适当变暗和轻模糊。固定头尾，内容独立滚动。
- 产品选择保留品类横滑、步骤胶囊、品牌/款式双列、搜索、反馈与底部选择摘要；不因美化擅自重构业务顺序。
- 输入框比面板更深；选中态使用低饱和紫底、细紫边、明确文字/勾选反馈，不能只靠发光辨认。
- AI咨询框可保留现有缓慢流动紫色边线；搜索框和订单字段保持静态。
- 关闭按钮精细、清晰，具备足够触达区；弹层关闭后焦点返回入口。

### 图标、光线、Banner

- 复用现有项目的 Phosphor / Tabler 图标资产；单一模块优先使用同一家族，统一约 1.5–1.8 px 视觉笔画。
- 光线色为青蓝、淡紫与少量暖金；光源集中在轨道节点或卡片局部。装饰使用低透明度且不承接点击。
- Banner：文案在左、主题图形在右；文字区域保持安静深底。沿用同系列光环资产，不能贴入异质宣传海报。
- 价格采用柔和金色；仅金额强调，币种符号稍小。没有明确来源时不能添加“起”、划线原价、优惠价或折扣条件。

## 6. 动效与可用性

现有节奏：技能轮播间隔 5.2 秒、卡片位移 1.1 秒；Banner 间隔 7.8 秒、切换约 .95 秒；咨询框边缘约 11 秒一周。新同类组件沿用该缓慢节奏。

- 小按钮/选中反馈约 180–250 ms；页面/弹层进入 350–450 ms；不使用夸张回弹或连续闪烁。
- 展示动画不阻碍阅读、拖动和点击；用户操作时暂停/延迟自动切换。保留手动切换与暂停能力。
- `prefers-reduced-motion` 下移除连续装饰动画和自动运动，操作保持可用。
- 正文与实底达到足够对比；常规文本以至少 4.5:1、大字与必要控件以至少 3:1 为设计核查目标。带透明度、图片背景需按实际合成颜色检查，禁用态同时检查是否清晰可辨。
- 暗色界面优先靠文字和形状反馈，光效只能辅助。避免横向溢出、焦点跳动和固定栏遮住列表末项。

## 7. 避免固化的历史问题

小字号、重复 CSS 覆盖、满屏发光、复杂嵌套边框、仅靠紫色区分状态、巨大的商品卡和重复主按钮，都不是“保持一致”的必要部分。保留品牌语言，在本次授权范围内改善这些问题。

具体页面排布由用户当前任务决定；本规范不要求所有页面都加光球、展示 5 张卡片或使用同一种网格。
