# 第13版 · 图灵评鉴完整交互 Demo

本版补齐线下实物评鉴的完整体验，沿用图灵鉴X的深靛底色、蓝紫按钮、细描边圆角卡片和统一线性图标。以下为当前版本说明；后续章节保留历次改版记录。

## 体验流程

1. 从“专家鉴定 → 图灵评鉴 → 鉴别品类”进入提交页，费用随所选品类变化。填写商品寄回地址、查看或复制鉴定中心示例地址，上传商品正面图并确认协议。支持使用示例地址、示例商品图快速体验。
2. 点击“模拟支付”进入发货页。填写顺丰物流单号后发货，展示成功反馈和“去查看”入口。
3. 点击“去查看”进入订单进度；也可以从“侧边栏 → 鉴定服务 → 线下评鉴服务”重新查看订单、继续填写草稿或发货。
4. 订单进度按“用户发往平台 → 平台查验 → 平台寄回用户”自上而下展示。平台查验内依次为“平台已收货 → 平台查验中 → 平台查验通过”，通过后展示外观图、品类、证书编号、鉴别结论和报告入口；寄回后展示物流公司与单号。
5. 报告包含商品外观图、品类、鉴定编号、样品序列号、鉴定师与时间，保留整体符合度 **96 / 100（模拟评分）**。可返回进度，或分享不含收货资料的报告摘要。

新订单不会自动变成查验通过。发货后可展开进度页的“演示状态”，手动依次推进收货、查验、通过和寄回；各状态的时间按顺序记录。订单列表内同时提供一笔已完成的包袋示例订单，证书编号为 `EAWGMFHB`，可直接查看完整时间线和报告。

## 演示边界与数据

- 全流程在浏览器本地运行，**不产生真实扣费、真实订单、物流请求或鉴定结果**，未连接支付、快递或鉴定后端。鉴定中心使用明确标注的示例地址，请勿实际寄件。
- 新建演示订单、收货资料与商品图片保存在 `sessionStorage` 当前浏览器会话中。刷新可恢复同一会话内的数据；不同会话不保证共享或保留。
- 用户选择的图片先在本机压缩，再用于订单、进度和报告展示，**不会上传到服务器**。用户图片与地址不会写入页面 URL；报告分享摘要不包含地址、手机号或图片。
- 若浏览器存储不可用或空间不足，会提示保存失败；当前页面仍可继续体验，但刷新可能丢失本次数据。
- 提交前校验姓名、手机号码、地区、详细地址、商品图片和协议；发货前校验顺丰单号。重复支付或重复提交相同单号不会重复创建订单或推进状态。

# 图灵鉴X · 首页源码（第 9 版）

基于用户提供的首页 HTML 开发。AI 首页采用单排五张卡片的弧形轮播，覆盖全部 20 个技能；专家页使用指定的新标题，并与 AI 页共用导航和蓝紫配色。

## 运行

无需安装第三方依赖。在项目目录运行：

```sh
python3 -m http.server 8796 --bind 127.0.0.1 --directory public
```

浏览器打开 http://127.0.0.1:8796/ 。专家页可直接访问 http://127.0.0.1:8796/?tab=expert 。

如已安装 Node.js，也可以用 `npm run dev` 启动相同服务（仍需 Python 3）。

## 构建与部署

运行 `npm run build`，将生成可部署到任意静态托管的 `dist` 文件夹。无需 npm install。`.openai/hosting.json` 是当前 Sites 部署配置，不是微信小程序配置。

## 文件说明

- `public/index.html`：首页结构、专家页内容、输入框与弹层。
- `public/original.css`：用户原始 CSS，作为样式基础保存。
- `public/app.css`：页面布局、轮播、输入区等基础样式。
- `public/spectral.css`：AI 页光感、两种模式共用的导航、紧凑布局及按钮细节。
- `public/expert-refinement.css`：专家页的标题、轨道、CTA、数据和协议区。
- `public/app.js`：卡片/Banner/话题轮播、技能选择、本地图片和演示咨询。
- `public/data.js`：原始技能数据及 SVG 数据。
- `public/assets/icon-map.js`：20 个技能的独立图标映射。
- `public/assets/`：三张 Banner 及图标；无需外部 CDN。
- `build.mjs`：把 public 复制为 dist 的静态构建脚本。
- `design-qa.md`：本版检查记录。

图标采用 Phosphor 与 Tabler 官方 SVG，来源和 MIT 许可保存在 `public/assets/icons/`。

## 本版修改

- 按最新截图恢复产品页的标题胶囊、完整品类横滑面板、胶囊步骤条、双列搜索列表、紫色反馈按钮和横向确认底栏。保持导航下方 14px 的弹层位置和高度。
- 品类页增加蓝/紫/暖金图标底托、名称与价格的两层排版，复用首页光环素材作为轻量装饰。
- 演示美妆目录增加截图中的 CPB、Creator、CREED；AI 角标由品牌或款式的 `ai` 字段驱动，金色服务标签由款式对象的 `badge` 字段驱动。普通款式仍可使用字符串。
- 款式列表使用单选语义，支持方向键、焦点跟随滚动和单一 Tab 停靠点。

- 专家页点击“立即鉴定”直接打开半弹层，顶端位于导航下方 14px。品类页与品牌/款式页使用同一外框，切换时高度不变。
- 按参考截图两列顺序提供 28 个品类，保留全部价格数值（统一显示两位小数）。品类列表纵向滚动，返回时恢复滚动位置。
- 品类进入品牌/款式双列选择：可搜索，支持无结果提示，切换品类后清除旧品牌与款式。非品牌品类使用种类/细分类型。
- 底部固定已选产品、价格、协议和确认按钮。确认前校验协议；确认仅展示演示结果，不创建订单、不收费、不上传资料。
- 产品反馈可在本次会话中填写和记录，不发送至客服；协议可在弹层内查看并返回。
- 具备焦点管理、键盘操作、关闭/返回、减弱动效支持及窄屏滚动布局。
- 首页卡片绑定角标、卡片轮播、Banner 和咨询功能沿用前版。

## 交互范围

支持轮播自动播放/暂停、跟手滑动、箭头/方向键批量切换、20 项技能选择、话题填入、最多三张本地照片预览/移除、文本咨询演示及专家协议展示。

本源码是网页交互 Demo，不是真实 AI 鉴定服务，不创建真实订单、不收费。第13版新增的线下演示订单与照片仅在当前浏览器会话中保存和展示。尚未接入真实后端，也不是已发布的微信小程序。专家服务文案来自用户素材及指定文案。
